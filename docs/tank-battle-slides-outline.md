# 坦克大战（Battle City）HTML 演示文稿大纲

---

## 设计风格总览

- **主题**：复古像素风 / 8-bit 红白机美学
- **氛围**：军绿、砖红、米黄、深灰，唤起街机厅与家用机黄金年代记忆
- **字体**：无衬线中文字体（Microsoft YaHei / PingFang SC / Noto Sans CJK SC）+ 像素感标题阴影
- **装饰**：粗边框、硬阴影、方块化徽章、像素网格示意图

## 复古像素风配色方案

| 角色 | CSS 变量 | 色值 | 用途 |
|------|----------|------|------|
| 背景主色 | `--bg` | `#1a1c18` | 页面背景、投影底色 |
| 面板色 | `--panel` | `#23251f` | 幻灯片卡片背景 |
| 军绿色 | `--army` | `#6b8c42` | 主标题、玩家坦克、强调边框 |
| 砖红色 | `--brick` | `#a04030` | 副标题阴影、按钮、徽章、敌方强调 |
| 米黄色 | `--cream` | `#f4ecd8` | 正文文字、图标高光 |
| 暗米色 | `--cream-dim` | `#d6cdb2` | 辅助说明文字 |
| 钢灰色 | `--steel` | `#7a7e85` | 钢墙、进度条、中性元素 |
| 水蓝色 | `--water` | `#3b6e9e` | 水域方块 |
| 雪地白 | `--snow` | `#dce3e8` | 雪地方块 |
| 草地绿 | `--grass` | `#4a7c36` | 草地方块 |
| 金币黄 | `--accent` | `#e0c040` | 道具、老鹰基地边框、高亮 |
| 阴影黑 | `--shadow` | `rgba(0,0,0,0.45)` | 硬阴影、层级感 |

### 配色应用原则
1. **背景深、文字浅**：深灰绿背景 + 米黄文字，长时间观看不刺眼。
2. **标题用军绿 + 砖红阴影**：营造像素块堆叠感。
3. **正文用米黄，强调用金币黄**：保持可读性同时突出重点。
4. **地图示意忠于原版**：砖墙棕、钢墙灰、草地绿、水域蓝、雪地白。

**完整文字内容：**

> 操作方式
> 方向键控制坦克上下左右移动，空格键或射击键发射炮弹。游戏支持双人同屏协作，共同防守基地。
>
> 胜负条件
> 消灭全部敌方坦克即可过关；老鹰基地被摧毁或玩家生命耗尽则游戏结束。

>
> 关卡机制
> 每关敌人数量固定，地图由 13×13 的像素网格组成，随着关卡推进，敌方数量和强度逐步提升。

**关键要点：**
- 操作方式：方向键移动，空格/射击键发射子弹
- 胜负条件：消灭全部敌方坦克获胜；老鹰基地被摧毁或生命耗尽则失败
- 敌我坦克：玩家坦克可强化升级，敌方坦克分普通、快速、重装等类型
- 关卡机制：每关敌人数量固定，击破特定坦克随机掉落道具

## 第 5 页：网页版设计 / 特色

**主题标题：** 网页版设计 / 特色

**完整文字内容：**

> Canvas 2D 渲染
> 使用 HTML5 Canvas 绘制地图、坦克、子弹与爆炸动画，流畅呈现像素风战斗画面。
>
> 像素风美术
> 保留原版 8-bit 像素质感，同时适配现代高分屏，让经典画面在浏览器中清晰重现。
>
> 键盘操作
> 监听键盘事件，实现坦克移动、转向与射击的即时响应，支持自定义按键。
>
> 关卡与 AI
> 地图以 JSON 或二维数组配置，敌方坦克具备巡逻、追踪、射击等状态机行为，可扩展难度曲线。
>
> 响应式布局
> 支持桌面与移动端全屏显示，提供暂停/继续功能与触屏虚拟按键，随时随地都能来一局。

**关键要点：**
- Canvas 2D 渲染：使用 HTML5 Canvas 绘制游戏画面与动态元素
- 像素风美术：保留原版 8-bit 像素质感，适配现代高分屏
- 键盘操作：监听键盘事件实现坦克移动、转向与射击
- 关卡与 AI：设计可配置的关卡地图，实现敌方坦克寻路、巡逻与攻击 AI
- 响应式布局：适配不同屏幕尺寸，支持全屏与暂停/继续
