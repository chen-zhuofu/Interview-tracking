# 英雄无敌3 中等版网页游戏开发计划

## 目标
创建一个单文件 `heroes3.html`（内联 CSS/JS）的英雄无敌3风格回合制策略网页游戏，使用 Canvas 2D 渲染，零构建，最终通过 `python -m http.server` 部署。

## 任务拆分

### Task 1a: 项目骨架与目录结构
- 创建 `heroes3.html` 单文件骨架。
- 创建 `docs/superpowers/plans/` 目录与本计划文件。
- 验证 HTML5 基础结构、UTF-8、viewport、标题、内联 style/script、玩法说明注释。

### Task 1b: 内联 CSS 基础布局
- 顶部资源栏（金币、木材、矿石、回合信息）。
- 左侧信息面板（英雄、城堡）。
- 中部地图区（Canvas）。
- 底部操作说明与结束回合按钮。
- 模态窗口（招募、战斗、游戏结束）。
- 启动 `python -m http.server 8000` 并用 curl 验证可访问。

### Task 1c: Canvas 2D 启动与渲染循环桩
- Canvas 尺寸自适应与高清屏支持。
- 游戏状态管理对象。
- 主渲染循环（requestAnimationFrame）。
- 键盘/鼠标事件监听桩。

### Task 2: 数据模型
- 阵营、英雄、兵种、资源、城堡数据结构。
- 定义基础兵种属性（攻击、防御、伤害、速度、生命、成本）。
- 英雄属性（攻击、防御、移动力、魔法）。
- 城堡与建筑配置。

### Task 3: 地图系统与渲染
- 10×10 网格地图，不同地形（草地、森林、山地、水域）。
- 地形移动力消耗。
- 地图对象：资源点、城堡、英雄位置。
- Canvas 绘制地形、网格、单位、资源图标。

### Task 4: 英雄移动与回合制循环
- 英雄每日移动力。
- 点击相邻/可达格子移动。
- 回合结束按钮推进日期并切换玩家/AI。
- 迷雾/可见区域（可选简化版）。

### Task 5: 城堡管理与兵种招募
- 城堡驻军与兵种招募面板。
- 招募消耗资源。
- 新部队加入英雄或城堡。
- 城堡收入（每日金币）。

### Task 6: 战斗系统
- 英雄相遇触发战斗。
- 按速度排序行动。
- 攻击/反击、伤害计算。
- 士气/幸运简化处理。
- 战斗结果：胜负、经验、部队损失。

### Task 7: 简单 AI
- AI 回合自动：招募、收集资源、追击弱敌、占领城堡。
- 基础决策优先级。

### Task 8: UI 布局与信息面板
- 资源栏、英雄/城堡详情、底部提示。
- 模态窗口：招募、战斗日志、游戏结束。
- 中文界面。

### Task 9: 游戏胜利/失败与存档
- 胜利条件：击败所有敌方英雄并占领所有城堡。
- 失败条件：失去所有英雄和城堡。
- 游戏结束画面与重新开始。
- 本地存储存档（可选）。

### Task 10: 本地测试与跨机器部署验证
- 单元测试验证 HTML/结构。
- 启动 `python -m http.server 8000`。
- curl 返回 200。
- 报告本机可访问 URL（含 IP）。

## 技术约束
- 单 HTML 文件优先，内联 CSS/JS。
- ES6+ JavaScript。
- Canvas 2D 渲染。
- 中文界面。
- 零构建工具。
